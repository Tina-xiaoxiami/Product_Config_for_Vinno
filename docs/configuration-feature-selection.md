# 配置功能来源与模板选入

2026-11-03。功能名称和IPN使用配置系统既有主数据，白皮书系统也已只读使用该配置库。本系统不另维护正文、图片或白皮书描述修订，也无需绕经白皮书功能库再次获取同一配置身份。

## 入口收敛

- 产品知识库只保留问答查询、历史版本追溯、参数型答案。功能主数据、注册与策略、资料管理不再作为知识库标签重复展示；引用和原文访问保留。
- 不再提供独立“功能管理”标签。模板管理承担从共用配置功能库选入功能、设置分类与探头支持的操作。旧 `/feature-manage` 和知识库旧功能链接转到模板管理，注册和资料旧链接进入已有管理模块。
- 原有功能身份、分组、名称/IPN关系及历史记录继续保留。移除页面不等于删除数据；已有模板、探头配置、版本及名称核对仍使用稳定的功能ID。

## 选择与生效范围

模板矩阵仅展示已选入的功能，选择器查询完整配置功能身份。初查主库171项中39项已用于探头矩阵，不能为了提供选择器就把其余132项全部自动加入。

在模板管理选择“从功能库添加”，选择既有功能、功能分类和支持的探头类别。分类沿用共用功能组，提交后会影响该功能的共用分类，界面须明确说明；不修改配置项的名称、IPN或白皮书正文。模板按探头类别配置，不在此新增系列或具体型号的强制覆盖。

新增选入先进入模板草稿，与现有支持单元格草稿一起提交；未提交时显示待提交预览，不作为正式支持。废弃草稿不改变正式成员、分类或支持值，也不删除功能身份。已选入项通过现有矩阵编辑，选择器不重复新增身份或覆盖已有条件支持。

## 版本与保全

既有 `probe_matrix_enabled` 作为模板/探头读取共用的选入标识；新成员分类意向临时保存于专用草稿，支持值仍复用原模板草稿。提交在同一事务完成选入、分类、支持值及版本快照，校验分组、探头类别与功能仍存在，并检测保存后被其他操作修改的成员状态。

新版本快照同时记录模板支持单元格及已选成员/分类。回滚保留功能ID及名称、IPN关系，不删除或重建身份；有未处理草稿时先处理草稿，避免覆盖待办。恢复分类仅针对该版本已选成员，移出矩阵的非成员保留当前共用分类，不回滚模板外主数据。旧版本只有支持单元格，保持其原恢复语义，并明确旧快照不包含成员和分类。

功能库同名、相关IPN或版本关系不用于自动复制/合并身份。独立页面取消后，既有名称核对标记、审阅记录及只读查询接口继续可用。核查时已有202条模板配置、3个模板版本、883条产品探头配置、78条探头草稿、349条名称记录和173条IPN关系，均不随页面取消删除。

## 副本验收

在真实主库的在线备份副本中完成完整操作：171个身份中矩阵仍只读39项；选入功能后预览40项，但正式标志、分类和支持单元格未改变；废弃后恢复39项；再次暂存并提交后才启用成员、分类和支持值并保存v2快照；回滚v2基线恢复39项，171个身份仍保留。旧快照回滚明确提示只恢复支持单元格，草稿未处理时拒绝回滚。

试操作只写验收副本，未对正式模板、系列或型号配置执行保存、提交或回滚。

## 本机结果与验证

2026-11-03已在线备份、合入现有运行分支并重启。正式接口返回171个身份、39个矩阵成员、132个未选候选，模板草稿和新增选入草稿均为0。只新增空的 `template_catalog_drafts` 表，原有75张业务表全部原始行摘要与备份一致；模板202条、版本3个及产品探头配置均未由验收操作修改，保留了并行任务修改。

Chrome实机只读验证：知识库仅3个标签，原 `/feature-manage` 自动进入模板管理且不再出现独立功能管理标签；打开选择器，按IPN查到既有功能，可选择共用分类和13种探头类别，未默认全选。表单试填后取消，未保存正式草稿或提交版本。短窗口下正文区域可滚动，页头和保存/取消操作区始终可见。
