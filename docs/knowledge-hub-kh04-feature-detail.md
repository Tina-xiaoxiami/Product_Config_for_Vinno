# KH-04 通用功能详情与原文联动

入口：产品知识库 → 功能详情（`/knowledge?tab=feature-detail`）。复用现有功能身份，不新增VATT专属页面、维护库或正文编辑器。

## 查询与来源边界

- 功能搜索复用已确认名称与IPN关联。主功能、关联版本、参数或组合成员逐项保留，关联版本选型不汇总成主功能支持结论。
- 市场、完整机型和软件版本限定资料查询；配置快照独立选择。快照IPN和正式选型沿用参数查询的快照归一化及身份检查，研发配置只作辅助。
- 未选快照不按软件版本或最大版本号自动代选；缺IPN或快照项时给出缺口，不按名称、实时配置补推。
- 当前资料沿用受控检索的范围、active状态和摘要约束。详情再检查功能名称明确命中，避免模糊检索引入其他功能。
- 仅功能详情显式启用DOCX标题上下文：复用已索引的`section_name`，展示同标题正文原片段。普通问答的排名与响应保持原样，XLSX工作表不据此扩展。最多展示50条并提示上限，原件仍可打开。
- PDF原页、Word段落仍为各自来源，不拼成统一参数或性能承诺。点击复用既有原件摘要和位置核验；结构定位不等于视觉或人工确认。
- Release历史复用原有追溯服务。最早记载、条件证据、当前配置与注册资格相互独立；无当前版资料不套用旧版本正文。
- 切换功能或范围立即清除旧结果，迟到响应不能恢复旧选择。机型目录和配置列表失败均可在原页重试。查询与原文预览不调用模型、不创建业务记录。

## 已核对实例

2026-11-14只读核对：国内ULTIMUS 6S，软件1.51.90、配置快照28（1.51.90正式版），功能21的IPN6000358为选配。登记PDF106第7页、DOCX107第235–237段分别定位；原件与提取摘要核验通过。该范围仍缺明确适用Release Note，未将其他系列正文继承为本机型结论。

国内/海外VINNO10的1.14.82配置分别来自快照30/29，VATT均为选配。该资料版本未命中白皮书正文，保留既有历史Release记录与限制，不跨版本补成当前说明。
