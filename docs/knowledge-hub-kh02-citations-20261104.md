# KH-02 引用定位与核验进展（2026-11-04）

本轮将资料问答的引用接回受控原件，并复用指南管理已有的原页图像核验。范围、配置、注册、参数的确定性规则及人工发布流程沿用现有实现，没有新增业务表或发布正式答案。

## 已完成

- “定位并核验原文”按文档ID、文件SHA256、真实PDF页号和原文短引读取完整上下文并高亮；原件链接携带引用版本。原件替换、提取过期、片段摘要变化、错误短引或无效位置分别拒绝，不静默打开另一版本。
- 非PDF材料候选按既有片段ID及章节、表格行或工作表行查看。旧无摘要候选仍是未核验候选，不补造版本或PDF页号；明确摘要冲突不进入候选。
- 引用查看与版本锁预览均禁止缓存核验响应；原件响应发送已核对的字节快照，避免校验后另读被替换文件。旧无版本手工引用保留原入口，不宣称完成版本核验。
- 原件路径仅由服务端白名单经临时0600清单传给共享进程，不进入HTTP输入、检索文本或模型。清单与本次资料ID/版本/授权页绑定，处理后清理。
- 所有资料回答PDF页显式要求看原页，复用指南 `translations.page_image` 与 `qa_vision.review_claims`。每次最多4个原页、一次视觉调用；正常共5次，发生引用修正最多6次。缺图、模型无图片能力、图像不清、条件缺失、不完整核验和预算不足仍保守处理，未看图数值不输出；人工状态始终未确认。
- 查看器关闭、重开、迟响应、问题/范围/结果变化及切标签均隔离；长内容在弹窗内滚动，保留固定标题和关闭入口。

## 验证

产品后端78项相关回归通过；新来源服务/资料回答/桥接定向48项通过，覆盖率91%/88%/95%，限定3模块mypy通过。前端全量723项通过，新增标签关闭接线后19项定向通过，生产构建通过。指南137项相关回归通过，产品机制74项，两个新改模块覆盖92%/90%，限定mypy通过。Python、TypeScript/JavaScript及跨项目代码复审通过；新增缓存和关闭提醒已修正后复核。

从产品服务通过SQLite只读连接执行一次真实V6升级限制问题，1.3运行器返回3条聚焦结论（平台前提及升级路径，中英文存在重复表述），6次实际模型调用含引用修正；原页视觉检查3条完整，渲染4页；6处短引全部通过精确版本、位置及原文匹配。候选上限仍如实标partial，不声称穷尽。原始问答、图像和日志只在本机忽略目录。

浏览器使用独立只读页面回放同一次真实结果，原文接口实时读取登记库与原件，避免为了验收页面重复付费或生成正式问答。验证展开引用、原文高亮、原页文件第3页、折叠与关闭，不把回放计作第二次真实模型验收。
