# 产品配置管理系统需求文档

## 1. 项目概述

### 1.1 项目背景
产品配置管理系统用于管理产品系列的配置数据，支持Excel导入导出、版本管理、配置对比等功能，实现配置数据的结构化存储和可视化展示。

### 1.2 目标用户
- 产品研发人员
- 配置管理人员
- 项目经理

### 1.3 核心价值
- 结构化存储配置数据，替代Excel手工管理
- 版本追溯，支持历史版本对比和回滚
- 多型号配置对比，快速发现差异
- 数据校验，确保配置数据准确性

## 2. 功能需求

### 2.1 产品系列管理
- 创建、编辑、删除产品系列
- 产品系列列表展示
- 每个系列下包含多个产品型号

### 2.2 产品型号管理
- 在系列下创建、编辑、删除产品型号
- 型号信息包括：名称、描述、状态
- 型号列表展示

### 2.3 配置数据管理
**核心功能，配置项为全局通用，配置值关联到具体型号。**

- 配置项字段：
  - 分类（Main Unit / Optional Features等）
  - 研发名称（rd_name）
  - V码（v_code）
  - IPN号
  - 中文描述
  - 英文描述

- 配置值字段（每个配置项针对每个型号）：
  - 当前配置（current_config）
  - 最终配置（final_config）
  - 选型配置（selection_config）
  - 研发状态（rd_status）

- 功能：
  - 配置数据表格展示（行=配置项，列=型号）
  - 单元格编辑
  - 批量修改（选中多个单元格，统一修改值）
  - 数据筛选（按分类、关键字搜索）
  - 下拉选项（选型配置、研发状态从现有数据提取枚举值）

### 2.4 Excel导入导出
**关键功能，支持多级合并单元格解析。**

- Excel结构：
  - 第一行：产品型号名称（横向合并单元格）
  - 第二行：配置状态类型（当前配置、最终配置、选型配置、研发状态）
  - 后续行：配置项数据

- 导入功能：
  - 文件上传
  - 预览解析结果（显示识别的型号、配置项数量）
  - 确认导入
  - 选择目标产品系列

- 导出功能：
  - 按系列导出配置数据
  - 保持Excel合并单元格格式
  - 下载模板文件

### 2.5 版本管理
**参考超声参数系统的版本管理机制。**

- 版本创建：
  - 从当前数据创建快照版本
  - 自动生成版本号（v1.0.0递增）
  - 支持手动指定版本号、版本名称、描述

- 版本列表：
  - 显示版本号、名称、发布时间、配置行数
  - 支持编辑版本信息

- 版本对比：
  - 选择两个版本进行对比
  - 显示新增项、删除项、修改项
  - 修改项详细展示（型号、字段、原值、新值）
  - 导出对比结果为Excel

- 版本回滚：
  - 回滚到指定历史版本
  - 回滚后创建新版本记录

- 版本保留策略：
  - 最近30天的版本全部保留
  - 超过30天，每15天保留一个版本

### 2.6 配置对比
**支持多个型号之间的配置对比。**

- 选择多个型号进行对比
- 按字段对比（当前配置、最终配置、选型配置、研发状态）
- 差异高亮显示
- 支持仅显示有差异的行

## 3. 非功能需求

### 3.1 性能要求
- 配置数据表格支持分页加载
- Excel导入支持大文件（MB级别）
- 版本对比响应时间 < 3秒

### 3.2 易用性要求
- 界面简洁，核心功能一目了然
- Excel导入流程清晰（上传→预览→确认）
- 下拉选项自动提取，无需手工配置

### 3.3 数据安全
- 版本快照不可修改
- 回滚操作创建新版本，不覆盖历史
- 删除操作有确认提示

## 4. 数据模型

### 4.1 核心表结构

| 表名 | 说明 |
|-----|------|
| product_series | 产品系列 |
| product_models | 产品型号（归属于系列） |
| config_items | 配置项（全局通用） |
| config_values | 配置值（配置项+型号的组合值） |
| config_versions | 版本快照 |
| change_logs | 变更日志 |
| draft_batches | 草稿批次 |
| config_drafts | 配置草稿 |
| import_history | 导入历史 |

### 4.2 关系说明
- ProductSeries (1) → (N) ProductModel
- ConfigItem (1) → (N) ConfigValue（每个配置项对应每个型号的配置值）
- ProductModel (1) → (N) ConfigValue
- ConfigVersion存储JSON快照，包含当时所有配置数据

## 5. 技术方案

### 5.1 技术栈
- 后端：FastAPI + SQLAlchemy（异步） + SQLite
- 前端：Vue 3 + Element Plus + Vite
- Excel处理：openpyxl

### 5.2 端口配置
- 后端端口：8086
- 前端端口：3006

### 5.3 API设计
遵循RESTful设计规范：
- GET /series - 获取系列列表
- POST /series - 创建系列
- GET /models - 获取型号列表
- GET /config/rows - 获取配置数据
- POST /import-export/import - 导入Excel
- GET /import-export/export - 导出Excel
- POST /versions - 创建版本
- POST /versions/compare - 版本对比
- POST /versions/{id}/rollback - 版本回滚

## 8. 附录

### 8.1 配置状态说明
- 当前配置：当前生效的配置值
- 最终配置：目标配置值
- 选型配置：选型类别（可选）
- 研发状态：研发进度状态

### 8.2 版本号规则
格式：v主版本.次版本.修订号（如v1.0.0）
创建新版本时修订号自动递增。
