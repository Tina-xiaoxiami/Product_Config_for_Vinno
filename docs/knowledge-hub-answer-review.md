# KH-02 系统内答案核对与全文查看

2026-11-02：在现有产品知识库的问答区增加核对入口，不增加独立业务页面。

## 使用方式

打开产品知识库 → 点击“待核对 18” → 点击任一行“核对”。弹窗显示原问题、答案全文、原有确认/变更说明及文档引文。表格新增答案摘要，点击“全文”可展开阅读。

- **仅补确认记录**：登记实际核对人、已有确认记录或资料定位及适用性，不修改答案原文，不自动建立查询范围。
- **确认范围并用于查询**：明确国家、市场、完整机型和具体软件版本后，为所选机型建立隔离的问答。原历史问答保留；已有不同答案时阻断，不覆盖。
- **暂缓，记录待办**：保存实际核对人及暂缓理由，继续出现在待核对队列。

核对人由用户填写；界面可沿用用户本会话亲自保存的名字，不冒用历史确认人。历史确认说明作为已有依据展示，不能替代本次用户操作。软件版本不适用或未知可以记录，但不能据此创建通配查询范围。核对数据绑定答案版本、内容/证据摘要和核对修订号；过期保存返回409并保留输入。失效答案禁止借核对流程重新发布。

## 数据与备份

新增 `knowledge_answer_reviews` 记录实际核对操作。来源答案、问法、询问次数、修订历史均保留。待核对是维护队列，可跨范围列出；日常查询继续执行国家/市场/机型/软件版本隔离。没有自动确认18条业务答案。

现有问答快照v1/v2只覆盖问答内容，**不包含核对操作记录**。保全核对记录须使用整库SQLite在线备份；不能用旧快照替代整库备份。数据库结构迁移使用既有显式迁移CLI并先备份，不随每次启动自动迁移。
