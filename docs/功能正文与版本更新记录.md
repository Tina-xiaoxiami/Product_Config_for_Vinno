# 功能正文与版本更新记录

功能发布 → 查询 → 功能 → Release Note → 完整描述。输入功能名称，查询后左侧阅读正文，右侧处理待核对更新。白皮书仍在同一功能的白皮书 Tab 独立展示。

## 三类内容

| 内容 | 作用 | 操作与恢复边界 |
|---|---|---|
| 功能正文 | 保存主要功能、适用范围、参数、操作和图示 | 编辑正文或更新正文才产生正文修订；恢复正文不撤销记录处理 |
| 版本更新记录 | 按原始版本记录迭代、优化、修复 | 采纳记录不改正文；忽略可撤销；恢复记录处理不回滚正文 |
| 正文修订历史 | 记录正文实际修改 | 保存来源版本、修改原因、修改前后与完整稿；恢复生成新修订 |

右侧优先使用「采纳记录」。需要修改正文时，点击「更新正文」，选择追加、替换或删除；替换/删除需先选左侧段落。预览确认保存后，同时采纳记录并生成正文修订。正文下方的更新记录按版本折叠；已采纳记录之后仍可用于更新正文。

## 草稿与保存

左侧默认显示「已保存正文」。编辑时自动暂存至当前标签页的 sessionStorage，「暂存草稿并关闭」仅关窗保留草稿，不改变正文、记录结论或修订号。正文上方会显示未提交草稿数量，并提供「查看修改 / 继续编辑」。查看修改仅显示与当前已保存稿不同的行；旧来源、旧修订或原记录变化时保留核对提示，不自动套用旧锚点。

「保存正文」成功后才更新左侧、写入正文修订并清理本次草稿；从更新记录进入时按钮为「保存正文并采纳记录」。刷新同一标签页后重新查询同一项目、功能与目标版本可恢复草稿；关闭标签页后不保证保留，草稿不是系统中的持久修订。

本轮草稿可见性补充验证：134 项相关前端测试、JS 语法与代码审查通过；IAB 实测暂存后正文不变、查看差异、继续编辑及刷新后重新查询恢复。测试仅使用新建临时标签页草稿，未保存正式正文。

## 旧数据与来源变化

复用原修订表，采用独立正文/记录计数和全局并发修订号，既有行不改写。旧稿仅在来源指纹一致且自动补充原句完整、唯一匹配时，将系统追加内容移出正文；人工兼容性说明保留。来源改变或无法确定时保留全部旧稿，提示核对。新资料仅使改变的事件重新待核对，未变化的结论继承。旧修订只有同源且同期唯一纳入事件时才派生来源版本关联，歧义保持未登记。

## 修订历史阅读

正文修订历史采用左侧紧凑修订列表、右侧单条详情，默认查看当前修订。当前正文用状态标识，旧版才显示恢复操作；来源版本、修改原因与时间集中在详情顶部，旧稿兼容来源说明折叠保留。

历史和草稿共用按行定位、行内字符标记的差异展示：红色删除线表示删除，绿色下划线表示新增；相同长段落折叠为上下文，完整正文另行展开。差异计算有预算上限，大块变更超过上限时按整块标色，始终保留精确原文。保存时的 before/after 优先作为对比依据；旧历史仅在相邻正文来源指纹一致时派生对比，否则只提供完整稿，不推测修改前内容。查看与切换不修改正式数据，恢复沿用原有全局修订号和并发检查。

本轮验证：138 项相关前端测试、JS 语法、diff 检查和 JS/通用审核通过；IAB 实测当前修订三处具体增删文字标色、未改动上下文折叠、旧修订切换和来源1.51.90展示，未执行真实恢复或正文保存。

## 图示

默认展示目标范围内最近可核实版本的修改后图；修改前保存在折叠对照。明确图注或紧邻的明确前后对比格式可确定角色，普通多图不按位置猜测。未知对比图可人工选择并重新选择，选择独立保存并受来源指纹与并发检查约束；不能覆盖已明确的 before/after 或普通图。图片沿用原件路径、哈希、章节与类型/大小校验，原文预览保留全部图片。
