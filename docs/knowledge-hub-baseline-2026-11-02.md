## 2. 可重复执行的核查工具

新增 `backend/scripts/audit_knowledge_baseline.py`。直接读取现有表，不调用应用启动、迁移、提取、发布或模型服务。

```sh
python3 backend/scripts/audit_knowledge_baseline.py \
  --database /path/to/product_config.db \
  --release-database /path/to/feature_tracker.db \
  --feature-library /path/to/功能描述库.json \
  --publication-root /path/to/白皮书工作区/.发布记录 \
  --output /path/to/local-reports/baseline-new.json
```

- 主库必须显式提供。可选来源未选择、不可用、格式不合法与有效零记录分别报告。
- SQLite以URI只读连接及 `query_only` 查询，各数据库在独立读取事务内取数；跨来源不是原子发布快照。
- 默认只核对登记原件可访问性及登记摘要与提取摘要的一致性；增加 `--verify-file-hashes` 才重新读取原件计算哈希。不会更新登记摘要。
- 发布回执仅统计为“受控回执未验证/归档回执未验证”；即使目录可读且JSON结构正确，也不能解释为当前已发布、产物完整或通过发布门。
- 无文档引文的正式答案只进入 `needs_owner_review` 清单。该清单是导出报告，不是写回现有队列或撤销答案。
- 不输出原件绝对路径、配置内容、API密钥或答案正文；本机报告仍含问题文本和记录ID，按内部工作资料保存。
- 输出拒绝覆盖已有文件，拒绝写入显式输入、已登记原件位置及回执来源目录，包括这些路径目前缺失的情况。
- 回执根目录不可读返回不可用，个别任务目录不可读返回降级；不会把读取失败记为健康零值。

## 4. 跨项目最小来源契约

本轮只确定读取与关联要求，未创建正式关联或新增数据库表。

| 字段组 | 现有来源 | 后续约束 |
| --- | --- | --- |
| 来源身份 | 来源系统、现有记录ID及原文定位 | 所有ID带来源系统，不将两库相同整数视为同一实体 |
| 功能身份 | 配置功能ID、已确认IPN关系；文档库已有绑定 | 名称仅用于搜索；V代码受系列及已发布配置快照限制，多IPN与参数关系不自动归并 |
| 查询范围 | 国家、市场、系列、完整机型；注册基础型号映射；语言 | 国家/市场/机型不明不得给可能受范围影响的肯定结论，语言不能代替市场 |
| 版本身份 | 软件版本、配置快照、资料版本、正文修订、问答修订 | 各类版本独立，不能相互替代，也不按最大版本号推断当前有效 |
| 资料依据 | 已登记文档ID、SHA-256、页码/段落/工作表位置 | 同一文档版本的DOCX/PDF分别校验，保留定位关系；只读原件 |
| 文档生产 | 文档编辑任务/轮次/构建/机型/语言/发布回执 | 生成完成、归档和正式发布分开；核验不合格的产物不能进入正式查询 |
| 内容状态 | 来源核验、业务确认、发布状态及生命周期 | 状态分开保存；模板变化、更新记录采纳和正文修订是不同动作 |
| 人工确认 | 既有负责人确认及问答修订 | 没有文档引文时明确确认人、日期、范围与限制，不自动认定存在确认记录 |
