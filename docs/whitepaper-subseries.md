# 共用白皮书子系列

配置管理的机型选择器直接读取白皮书工作区的 `子系列.json`，按系列、子系列展示机型；可选中整个子系列，未归类机型显示在“其他机型”。已保存的浏览器机型组合继续使用。

在配置管理点击“编辑子系列”，可新增、改名、删除分组并调整成员。候选来自完整配置机型目录，尚无白皮书的机型也可加入；白皮书系统只使用其中已有文档的成员。两个系统读写同一份定义，不复制关系，也不改配置值或版本。多重子系列归属保留，选择时按机型 ID 去重。

保存使用共享锁、原子替换与修订校验。另一边修改后旧页面保存会被拒绝，保留当前输入；重新加载前确认是否放弃未保存的修改。已有白皮书短名称及其他文件元数据保持。白皮书服务更新后需刷新旧页面，获取新的修订号。

默认路径为 `~/Documents/Obsidian Vault/产品配置管理系统/白皮书工作区/子系列.json`。配置管理后端可用 `WP_VAULT` 指定白皮书资料库根目录，或用 `WHITEPAPER_SUBSERIES_FILE` 指定子系列文件。部署到其他电脑时需要共享工作区可读权限。

按系列和严格机型名匹配，保留版本限定词（URM、非URM、下划线等）。不会按部分名称推断归属。对应不唯一或源定义损坏时，在选择器提示；机型本身仍可选择。未设置父系列的定义可在实际对应的多个系列中展示。

## 命名子系列组合

在“编辑子系列”中点击“新增组合”，填写组合名称并多选子系列后保存。页面的“子系列组合”入口可一键切换到组合全部成员机型，支持跨系列选择并自动去重。组合保存对子系列的引用，使用时重新读取最新成员，不保存旧机型快照。

子系列改名时，配置管理编辑器会同步更新组合引用；删除已被组合使用的子系列前，先从组合中移除。白皮书编辑器同样会阻止产生悬空组合。组合中存在无法匹配的成员时，会提示先核对，不会静默只应用一部分。

组合存于共用定义的 `sub_series_combinations` 字段，与子系列一同原子保存并验证源修订。已有浏览器“机型分组”保持原有保存方式。

机型下拉框按“组合 → 子系列 → 机型”展示当前所属系列范围内的成员，组合和子系列默认收起，点击名称展开或收起。未加入组合的子系列及其他机型仍独立显示。搜索可匹配组合、子系列或机型名称，并自动展开结果；清空搜索恢复手动展开状态。重叠组合中的同一机型共享勾选状态，保留子系列整组选中入口。
