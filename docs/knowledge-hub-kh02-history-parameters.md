## 历史版本追溯如何操作

打开产品知识库 → **历史版本追溯**，填写主题、市场、完整机型和目标软件版本，点击**追溯历史**。来源国家可选；未填写时按来源国家与版本链分别展示，不把不同国家证据拼成无条件支持。也可先在问答区选范围，再点击**使用问答查询范围**。无同范围正式答案时，问答结果会附上相同的候选追溯结果。

结果按版本链分别展示，带事件版本、变化类型、资料页码/章节、原文及预览链接。硬件平台和升级限制独立显示，即使它们与查询关键词不在同一句。未命中不等于不支持，最早记载不直接等于首次支持；证据结果不会自动发布或覆盖正式问答。

原文已清楚声明的型号、版本、平台、整机V代码及升级路径直接提取并参与检索，每字段保留页码和原句，无需先建立人工关系。**维护资料适用范围**用于补充原文确实未明确的适用关联或设备硬件映射，不作为阅读源事实的前置审批。需要人工补充时选择已登记Release Note和完整机型，填写有依据的范围、版本链、平台限制和实际核对人。软件版本数字相近不能代替版本链依据，语言不能代替国家市场。错误关系可**停用**后重建，原记录保留；保存和停用都做冲突校验。

内容、文档范围、提取结果或机型身份变化后，旧适用关系不继续用于推断。原文不能确定的字段单列具体问题；国家/市场未声明只保留为来源边界，不阻止软件变化原文检索，也不能据此推出全球注册或某国正式选型。累计DOCX表格无法证明所属版本时保留原文并标为待核对，不继承末尾章节；否定新增/取消等语句也不当作真正变化事件。

## V6针增益调节真实验收

从原始材料目录找到此前未被现有VINNO10/ULTIMUS项目导入的V6 Release Note。首批选择三份可审阅PDF：

- V5EXP、V6、V8POC 1.14.40：原文涉及POC新硬件，不支持旧机器直接升级。
- V6、V6PRO、V6EXP、V5EXP 1.14.61：原文涉及硬件升级，不支持已发货机器升级。
- V3、V5、V6 1.14.65：V6限VLucid+平台，并明确从1.14.61升级。

三份资料经现有受控收纳、登记、提取管线演练，均未命中针增益调节的明确新增记录。它们未明确国家和市场，字段保持“原文未声明”；不再据此阻塞软件版本检索。原文事实以source_extract标识，不由AI冒填人工确认人或批准适用关系。

V10 1.14.40第11页的阳性记录不能作为V6依据。旧便携分支还发现1.12.45—49等材料，部分DOCX最终发布资格及目录版本与正文存在疑点，本轮不声称覆盖全部历史。真实验收结论为已检索原文涉及V6的历史资料、没有明确针增益新增记录；不能把未命中写成“不支持”。原文已确定的信息不再要求用户重复确认。支持新增、后续取消、早于新增版本、同号不同分支等正反例使用临时合成资料测试。

## 参数型答案如何操作

打开产品知识库 → **参数型答案**：

1. 点击**新建参数主题**，填写名称、问题和可选问法；添加参数名称、单位与数值/文字类型。例如“电池容量”可定义“容量/mAh”“能量/Wh”。内部字段标识自动生成，无需填写。字段定义创建后固定，避免重新解释旧规格值。
2. 点击**新增规格与IPN**，填写规格名称、唯一IPN、实际参数值、资料依据及本次核对人。规格可编辑或停用，每次修改保留修订，过期编辑不会覆盖别人已保存的记录。
3. 选择**配置系列 → 已发布配置版本 → 该快照中的完整型号**，点击**按配置匹配参数**。
4. 查看每个型号的规格、IPN、参数、正式选型类别及缺项；多个可选规格全部列出。可筛选完整结果、展开全文，点击**查看/复制答案**复用生成文本。

匹配按指定快照的IPN和 `selection_config`，研发 `current_config` 只作备注。配置版本使用版本ID，允许“1.51.90-正式版”等既有名称；不借用数字软件版本字段。预览不恢复或修改配置，也不自动发布正式问答。空值、未知选型、重复IPN、型号身份冲突及不允许支持都明确报缺项或问题。

V8Bat/V9Bat真实参数和未明确IPN关联不预填，现有6700mAh/96.48Wh文字答案不擅自绑定到任一规格；Wh与mAh不自动换算。新存储初始为空，用户填写后才可匹配。

当前主数据只有型号名、UUID和注册映射，没有VINNO 6及综合版到旧V10116、POC V10921、VLucid+硬件的唯一关系。一般历史检索不需要补这项；只有要判断具体设备/配置型号的支持或升级资格时，才列出目标硬件映射问题。普通“有哪些升级路径”查询不要求用户回答某台设备信息。

单一明确封面版本可直接作为源版本；索引版本缺失/不一致属于系统数据问题，不要求用户复述清楚的原文。坏摘要/过期提取不产生源事实或业务确认问题。多型号比较、排除与转折分别归属，单个型号的功能变化不会套给封面中的其他型号。
