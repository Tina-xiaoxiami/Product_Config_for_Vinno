# KH-02C：复用指南证据问答与旧问答清理

2026-11-04用户授权新增资料证据问答，并取消旧历史问答的逐项核对。普通问答复用、正式配置、注册规则和参数快照匹配继续沿用既有确定性实现。

## 使用方式

产品知识库 → 问答查询，明确市场、完整型号及软件版本后输入问题。原“查询答案”继续查询已确认答案；新增“查资料并生成草稿”只在明确点击时调用共用模型。结果标记草稿/部分支持，逐条展开原文引文并打开对应PDF页，不自动发布、不写正式问答。

型号正式选型、注册资格、按IPN匹配规格数值的问题（含中英文问法）转回现有确定性入口。原文明示的功能操作参数与历史变化可以取证；无记录不等于不支持，也不能把最早记载称为首次支持。

## 复用边界

指南仓库新增 `guidelines.product_evidence` 中立入口，实际调用现有 `meilisearch.Client/search_settings`、`ModelSettings/create_model`、`RunModel(use_skill=False)`、`build_segments/resolve_claims/validate_claims`、逐条支持性核验。模型密钥和服务商设置继续由指南管理持有。产品系统只提供已确定范围的原文页并将验证后的引用映射为本系统预览URL。

不直接调用医学专用 `qa.answer()`，不继承指南vault/card路径和医学提示；这两部分与产品机型/软件版本不兼容。全文服务共用，索引使用独立随机 `vinno_product_` 标识，单次结束清理；不更新指南索引或资料。

本机配置使用Git忽略的 `backend/config/knowledge_evidence.local.json`，格式见 `knowledge_evidence.example.json`。`guideline_project`指向包含共用运行器的已安装项目，`python_executable`可选；默认沿用服务进程Python。运行器用固定模块名、JSON stdin/stdout和超时限制调用，不从HTTP请求接收程序路径或密钥。部署需确保运行环境满足指南已有依赖，并运行其本机Meilisearch服务。

## 范围、证据和用量

- 资料先按现有完整型号/市场/版本及Release Note原文适用事实筛选；同市场同名型号无法唯一关联时拒绝取证。其他型号、晚于目标版本和未确认适用来源不因模型检索扩大范围。
- 只传有真实页号的受控PDF完整页，校验原件、登记和提取摘要。输入上限500页/4MiB；不可引用的空页、超长页和非PDF明确列缺口，不截断后宣称完整。
- 模型最多比较24个候选页摘要，读取8个完整页（含可用邻页），每次上限6次调用。真实片段ID由程序生成，文献/哈希/页号/原句由程序回填并验证，模型不能提供任意文件或URL。
- 当前未接入原页图像核验；图表/异常排版上的数值采用现有保守核验规则。不能把模型自检标为人工审定。
- 模型返回后再次核对范围及来源摘要。来源变化或引用失败不显示为有效草稿，已经发生的模型用量仍保留；运行器超时且无法确定调用数时记未知，不写成0次。
- 模型草稿、原文和实测结果留在本机受控/忽略区。共享模块摘要和实际服务商/模型身份随结果记录，用于后续缓存与失效核查；本轮不新建第二套持久缓存。

## 旧问答清理

用户明确要求删除截图所指旧历史数据。已只清理 `scope_key=''` 的41条问题、85条问法、40条答案、31条引文关联和40条修订；旧核对记录原为0。6张QA表当前为空，原“待核对18”不再保留为业务待办。其余74张业务表逐行摘要一致，91份资料及其提取、配置和参数保留。

执行前经过副本清理和原始行恢复演练。正式执行使用预览指纹、事务内再次校验、外键检查、独占原始行归档及SQLite在线整库备份；定向恢复拒绝ID/唯一键冲突，不覆盖后来形成的新问答。维护工具为 `backend/scripts/retire_legacy_knowledge_qa.py`，默认演练；执行或恢复必须显式提供参数及 `--apply`。真实归档及备份位于本机Git忽略区 `.runtime/tmp/legacy-qa-retirement-20261104/`，不提交GitHub。
