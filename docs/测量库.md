# 人用测量库

入口：左侧「测量库」，路径 `/measurements`。本期仅实现测量库，未接入 Release note 翻译。

## 来源和显示规则

- 导入 `MeasureItems_Human_Chinese.xlsx`，填写来源版本；读取第一张 `ItemCategories` 和第三张 `Calculations`。
- 英文 UI 名称为 `Description`，为空时原样使用 `Id`；中文 UI 名称为 `ChineseName`，缺失时保留空值并提示，不自动补译。
- 第二、第四张汇总表仅用于核对 Total，界面统计始终来自明细；不将汇总表的规则说明行当成业务数据。
- `Categories` 按分号拆分。`Common` 属于常规测量，其余为应用测量；同一行可关联多个应用。分类为空显示 `(空白)`，可通过「未分类」查找。
- 计算项保持独立的 Group、Unit 和 IsEnabled，不从 Group 推断测量模式或应用。
- IsEnabled 仅 TRUE/FALSE（不区分大小写，兼容布尔值）解释为已启用/未启用。空值及 `TURE` 等异常值为待核对，保留原值。未启用记录仍可查到。

## 查询和表格

搜索 Id、英文 UI 和中文 UI 名称，不区分大小写，名称精确命中在前、部分名称命中在后。保留撇号、斜杠等符号，避免将 E、E' 等不同项等同。当前条件未命中不代表整个版本或某机型不支持。

「测量项/计算项」和「常规/应用/未分类」与列筛选组合使用；同列多选为 OR，跨列为 AND。应用列按单个应用筛选，命中多应用记录不会复制行。

复用 `ProbeDataTable`、`TableColumnSettings` 及列布局存储。测量表启用每页 50 条，筛选及统计覆盖当前版本完整数据后再分页。浮层关闭自动应用选择，显示明确提示；空选、不限和仅空白分别处理。列设置支持宽度、顺序、可见性、固定、恢复默认以及未应用关闭提醒。详情显示完整文本及 sheet、原始行号。

## 历史及安全

每次导入创建不可变批次，保存来源版本、文件名、SHA-256、导入时间、统计和核对提示。同一文件内容与来源版本重复导入复用原批次；修订文件创建新批次。切换批次可查历史，不覆盖旧数据。

每条源行独立保存，Id 不作为全局唯一键；跨模式、跨应用同 Id 以及完全重复行均保留出处。页面区分明细行数和不同 Id 数，重复行计入明细数。

导入使用事务；文件损坏、结构错误或缺少必要字段时不写入。限制上传 16 MB、ZIP 解压后 64 MB、每 sheet 20,000 行及 64 列；来源文件本身只读。新增表随现有 `init_db()` 建立。

## API 和验证

- `GET /api/measurements?batch_id=<可选批次>`：未指定批次时返回最新批次，以及批次列表、完整源行、统计和核对提示。
- `POST /api/measurements/import`：multipart `file` 与 `version`，返回 `batch_id` 和 `reused`。不接收任意服务器文件路径。
- 后端：`python3 -m pytest backend/tests/test_measurements.py -q`。
- 前端：`npm test`、`npm run build`。
- 浏览器：沿用现有 Playwright runner 和隔离数据库；`measurements.spec.js` 覆盖页面导入、双语查找、应用/模式筛选、关闭自动应用、清除条件和列设置持久化。在 GitHub Actions Linux 环境执行；macOS 本机遵守全局浏览器权限规则。
