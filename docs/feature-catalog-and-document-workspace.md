# 功能全目录与资料管理入口

2026-11-03入口更新：知识库不再重复展示功能主数据、注册与策略、资料管理标签；独立功能管理页归并到模板管理，从同一配置功能身份库选入功能并设置共用分类与探头支持，不维护白皮书正文。本文保留此前目录补齐和数据保全记录，当前操作及版本边界见[配置功能来源与模板选入](configuration-feature-selection.md)。

## 功能主数据

功能主数据以现有 `features` 身份档案为唯一入口，纳入配置管理的全部 `Optional Features`。配置项数、不同 IPN 数和功能档案数分别统计：已有的相关 IPN、版本 IPN 继续归属原档案，不为同一关联重复建档。

`feature_catalog.sync_optional_feature_catalog` 只补录有唯一、非空 IPN 的缺失档案。中文、英文主名复用现有名称清洗规则，来源分别为配置中文、英文描述；缺少一种语言也保留档案，研发名称不替代正式主名。已有名称、别名、关系及人工关联保持不变。缺少 IPN 或重复 IPN 的配置项保留在覆盖缺口详情中，避免静默遗漏或猜测身份。

同步在应用启动、配置导入和历史配置恢复时执行，由调用方负责事务提交。导入预览的 SAVEPOINT 会一并回滚新增档案。重复同步不会创建重复档案。

`GET /api/knowledge/feature-coverage` 是只读统计，配置覆盖与身份确认、正文证据质量分别表达。缺中文/缺英文数与功能目录的缺名筛选采用同一全目录范围，包括只有相关或版本 IPN 的历史档案。

探头矩阵沿用 `probe_matrix_enabled` 范围：旧档案迁移默认启用；本次由配置目录新增的档案默认不进入探头矩阵。矩阵读取、批量操作、工作区及模板功能组筛选共用此范围。

## 资料入口合并

原始资料的管理统一在“功能发布 → 资料管理 → 原始资料”，地址为 `/release?tab=documents`。产品知识库里的“资料管理”直接进入同一页面；旧 `/knowledge?tab=documents` 链接重定向。

资料列表复用原有知识库接口及原档案，保留提取/重新提取、预览、本机打开、访达定位和归档。分页支持 50/100/200；筛选、加载失败重试、过期响应隔离及归档后末页回退由同一控制器处理。问答引用的资料选择与原文链接继续保留。

文件同步、发布版本、发布对比和功能版本管理继续作为发布工作流的子入口。原生资料页面不依赖工作台 iframe；切换到查询后再返回，后台 iframe 消息不会抢走资料页。
