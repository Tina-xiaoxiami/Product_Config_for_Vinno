# 功能名称核对

模板、探头矩阵和知识库中的名称标记可点击，打开「功能名称核对」。勾选已经核对的基准，填写可选说明后点击「确认所选差异」，表示沿用当前写法。两个基准分别确认，只有所有仍存在的差异均确认后才移除该功能标记。

确认不改功能主名、IPN、配置管理描述或导入标准。自动核对报告仍保留实际差异；「两个基准逐条核对」会显示已确认状态。功能管理中每个功能的「名称核对」入口可查看记录和撤销确认，标记消失后仍可进入。

记录包含功能身份、比较基准、事实指纹、当时核对内容、核对人、说明和时间（UTC）。指纹涵盖主名、别名、主IPN关联和比较内容；相关事实变化会使旧确认失效。记录不删除，撤销只记录撤销时间。接口先取得写锁再校验指纹，旧页面不能确认新事实，批量确认出现任一过期项时整批回滚。

存在多个主IPN关联或标准对应关系歧义时，不允许直接确认隐藏提示，应先核对功能身份。传入明确功能ID的界面只查询该ID的标记，不借用同名功能；没有ID且名称对应多个功能时不建立可写的名称索引。
