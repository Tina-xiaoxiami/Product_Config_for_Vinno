# 标准名称与配置链接

功能名称只以「功能名称标准表」为基准。名称不一致时点击标记，核对标准中文、英文名称后点击「按标准表更新名称」：更新功能显示名与中英文主名，旧名称保留为对应语言的曾用名；不修改 IPN、配置项、配置链接、机型差异或发布快照。

配置管理只检查主 IPN 链接关系：已链接、未关联、多个主 IPN；不比较配置项的中文/英文描述。白皮书名称也只按标准表判差异，配置中的历史描述仍可用于识别原有写法。

只有唯一、明确的标准映射可以直接应用；标准未收录、多个标准定义、多功能同名或多主 IPN 时需先维护对应关系。名称或标准发生变化时，旧指纹请求会被拒绝，避免覆盖新内容。

此前「确认沿用当前写法」记录保留供追溯，但不再隐藏名称差异；旧确认接口停止接受新确认。名称更新记录保留更新前事实和采用的标准，不能作为单纯的差异确认撤销。

# 应用关联草稿

探头&应用页中，暂存添加、移除、撤销会同步保存到本机浏览器草稿；刷新恢复编辑状态、类别与待提交变更。只有「提交并创建版本」才调用现有批量发布接口。正式类别应用不会因自动保存而改变。

界面明确显示「本机草稿已自动保存」；浏览器存储不可用或其他页面改写同一草稿时显示失败，并保留本页编辑和离开保护。废弃只在本机清理成功后报告成功；发布已成功但本机清理失败时单独提示并提供重试。重新提交恢复草稿前先读取正式关联，已经生效的变更不会重复创建版本。本机草稿不在不同浏览器或设备之间同步。

# 探头型号操作

「新增类别」位于左侧类别标题旁；「新增型号」「从配置补齐变体」和「批量变体」位于型号标题行。批量变体用于跨型号 Excel 维护，行内变体用于一个型号。从配置补齐仅按 Probes 的对外型号匹配已有探头，补充研发内部型号与 IPN，作用于全部类别，不新建探头型号。

# 全量标准名称同步与显示名称

已导入标准表后，管理脚本 `backend/scripts/sync_feature_standard_names.py` 支持预检与统一同步。匹配采用明确名称或已链接研发标识，保留 `+`、维度和版本限定；同一标准可以用于多个保留独立 IPN 的版本，不合并功能。无法明确对应标准的原记录保留并写入报告。无异常、名称已完全一致的匹配项也会生成核对记录。

执行时必须指定独立 `.json` 报告及备份目录；脚本先备份并核验完整性，整批名称和核对记录在一个事务中提交。仅更新显示默认名、中英文标准主名和曾用名，不修改 IPN、配置关系、机型差异或已发布快照。

每个当前功能的表头图标都可以进入名称编辑；没有异常时显示中性铅笔，直接打开「编辑显示名称」。可使用中文、英文或输入自定义短名，逐功能保存，允许同一张表混合显示。显示覆盖独立存储，标准名称同步不会覆盖它；恢复默认只清除显示覆盖。标准名仍是名称核对依据。

显示编辑器由应用稳定宿主承载，搜索结果、列结构或名称变化不会卸载正在编辑的弹窗；未保存内容仍受关闭和离开保护。历史快照使用原快照名称。
