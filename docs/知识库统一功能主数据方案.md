# 知识库统一功能主数据方案

状态：已上线到产品配置管理系统

确认日期：2026-09-01

## 1. 唯一身份

- IPN 是功能的业务唯一标识；
- 数据库内部保留整数 `id` 作为技术主键，现有外键继续引用 `id`；
- 单一IPN功能的 `features.ipn` 必须非空并建立规范化唯一约束；
- 一个旧功能名对应多个IPN时，`features.ipn` 保持为空，通过 `feature_config_item_links` 分别关联，不强行选择一个IPN；
- IPN 使用文本类型保存，规范化时只去除首尾空格并统一字母大小写，不删除前导零；
- 相同名称但IPN不同的记录不得自动合并。

## 2. 主名称和备用名

- `config_items.zh_desc` 是默认主中文名；
- `config_items.en_desc` 是默认主英文名；
- `config_items.rd_name` 是研发内部识别字段，只用于迁移匹配和内部检索，不作为可展示的主名或备用名；尾部 `【启用】`、`【禁用】`、`【停用】`属于状态并从名称识别中剥离；
- 现有 `features.name`、Release Note、白皮书、说明书及人工确认名称作为曾用名候选；
- 同一IPN允许一个当前主中文名、一个当前主英文名和多个中英文备用名；
- 主名称变更时保留旧名称、来源、有效期和审核记录，不覆盖历史。
- 中文、英文曾用名分别记录语言，但查询不按材料语言限制；中文材料中出现英文名同样能够命中功能。

## 3. 不作为普通备用名的关系

以下内容默认建立功能关系，不能仅因名称相似而自动合并为备用名；经产品负责人明确确认为同一功能时，可记录确认来源后归并：

- 父功能、子功能；
- 功能参数；
- 组合功能；
- 后继或替代功能；
- 相同名称但不同IPN的功能。

例如 `6000034 / 穿刺增强 / Needle enhancement` 是标准功能；“针增益调节”是参数，`6000301 / 自动穿刺增强` 是另一个功能身份。“穿刺引导&穿刺增强”已于2026-09-01经用户确认归并到 `6000034`，作为备用名保留。

## 10. 系统使用

- 启动系统后访问 `http://localhost:3006/knowledge`，或点击左侧“产品知识库”；
- “功能主数据”可按 IPN、中英文主名、中文曾用名、英文曾用名和研发内部识别名搜索，并可按自动匹配、人工确认、关系型功能筛选；研发内部识别名只参与检索，不在备用名区域展示；
- “国内注册与策略”可选择完整产品型号，按探头型号、IPN、注册状态和最终判定查询；
- 页面分栏展示“注册状态”“选型类别（正式）”“当前配置（辅助）”和“最终判定”：未注册只取注册差异表，已注册探头优先取正式选型类别，缺少正式选型时才展示研发当前配置作为辅助；
- `VINNO 9_Private` 和 `VINNO 9 综合版` 均以 `VINNO 9` 为注册基础型号，但产品策略仍读取各自完整产品型号；
- “注册差异表原文”使用受控文档 ID 打开登记的 Excel 原文件；
- “原始资料”可按资料名、版本、产品和资料类型检索；
- PDF 和图片使用受控文档 ID 在页面内预览；Word、Excel 等 Office 文件保留“打开原文”；
- 后端只接受数据库中已登记的文档 ID，不接受用户传入任意文件路径。

判定顺序固定如下：

1. 注册差异表标记为不支持时，最终判定为 `# 未注册`，即使研发当前配置为 `X` 也不得覆盖；
2. 已注册且“选型类别”存在 `X/O/Δ` 时，以选型类别作为正式产品策略；
3. 已注册但选型类别缺失时，`current_config` 的 `X/O/Δ` 仅作为研发辅助信息；
4. `current_config` 中的 `#` 不用于推导未注册，未注册只认注册差异表；
5. 注册表存在但配置系统尚无对应 IPN 的探头继续保留，策略显示“未定义”，不丢弃注册记录。
