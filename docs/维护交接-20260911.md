## 1. 项目在数据链中的位置

本系统是「超声产品」三条数据链中的**主数据源**：

| 系统 | 角色 | 真实数据规模 |

## 6. 上一轮联合评审结论（集成契约错位要点）

白皮书系统对本系统/参数系统的集成**从未对真实数据验证过**，主要错位：

| 白皮书系统假设 | 真实主数据 | 结论 |
|---|---|---|
| 系列用 `series_code`（docstring 举例"ULTIMUS"） | 配置系统 `product_series.name` = `R&V10 series-China`、`Tulip-China` 等 | ULTIMUS 是参数系统的"产品名"，两个标识符空间混用 |
| 选配标记词表 `O/Δ/X/#` | 实际取值 `X/O/Δ/未定义/N/A/NULL` 六种 | `#`（删除）真实数据中不存在；`未定义/N/A/NULL` 未处理 |
| 版本号 `v1.0.0` 格式 | `1.14.65` 与 `v1.14.71` 混存 | 字符串 BETWEEN 会错乱 |
| 修订历史读 `change_logs` | `change_logs` 0 行 | 永远返回空 |
| 技术参数走真实库 | 白皮书 `_get_param_data` 返回硬编码假数据 | 445MB 真实参数库未接入主流程 |

> 注：白皮书系统的原生 SQL 表名/列名与本系统 schema **是匹配的**（非"写错 SQL"），问题在**语义层标识符与词表**。
