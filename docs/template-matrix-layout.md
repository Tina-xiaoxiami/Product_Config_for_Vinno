# 模板矩阵的查看与列布局

- 底部横向滚动条和工具栏左右箭头可查看全部功能列；表格聚焦时也可按左右方向键。纵向滚动查看全部探头类别，表头常驻。
- 拖动表头右边缘调整该列宽度。也可打开「列设置」，通过数字输入精确调整宽度、显示/隐藏、排序和固定列；点击「应用」生效。「恢复默认布局」后应用可还原布局。
- 列布局按浏览器保存在模板矩阵专用存储键中；功能列使用功能 ID，改名、搜索或同名功能不会串用列宽。布局操作不计入草稿变更，也不清除已有未保存单元格。
- 长标题和单元格内容显示省略号，悬停可查看完整文字；名称核对标记仍可点击。编辑单元格仍使用原有支持状态与应用选择浮层。
- 本次只调整显示和个人布局，不更改模板、探头配置、机型差异或发布状态。

验证：布局工具单测覆盖独立列宽、重命名、隐藏、筛选、分组、固定列和新功能；浏览器用例覆盖 1440×900 与 860×600 的滚动可达性、拖动/刷新记忆、列设置及未保存编辑保留。
